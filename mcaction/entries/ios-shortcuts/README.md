# iPhone：操作按钮 / 背面轻点 / NFC / 闹钟 / 日历

所有 iPhone 入口都是「快捷指令 → 调用麦一下服务」。快捷指令文件带签名、无法用代码生成，下面按步骤手动搭，每个 3 到 6 个动作。

## 0. 让手机连得到服务

1. 在 `.env` 设置 `MCACTION_KEY`（随便一串长字符），服务会改为监听 `0.0.0.0`。
2. 同一 Wi-Fi 下用电脑内网 IP，如 `http://192.168.1.20:3790`；在外面用时可以开内网穿透，例如 `cloudflared tunnel --url http://localhost:3790`，并把外网地址写进 `MCACTION_PUBLIC_URL`。

下文用 `{服务}` 指代这个地址，`{KEY}` 指代 `MCACTION_KEY`。

## 1. 主快捷指令「麦一下」

供操作按钮、背面轻点、NFC 共用。按一次试算，60 秒内再触发一次就下单并打开付款页。

| # | 动作 | 设置 |
| --- | --- | --- |
| 1 | 文本 | 内容为「快捷指令输入」，没有输入时填 `auto` |
| 2 | 获取 URL 内容 | URL `{服务}/v1/press`；方法 POST；头部 `x-mcaction-key: {KEY}`；请求体 JSON：`scene` = 第 1 步的文本 |
| 3 | 获取词典值 | 键 `say` → 显示通知 |
| 4 | 获取词典值 | 键 `payPage` |
| 5 | 如果 | 第 4 步「有任何值」→ 打开 URL（第 4 步） |

想按当前位置找店：在第 2 步前加「获取当前位置 → 获取地址详细信息（城市 / 街道）」，请求体多传 `city`、`keyword` 两个字段。

## 2. 绑定触发方式

| 入口 | 设置路径 | 适用机型 |
| --- | --- | --- |
| 操作按钮 | 设置 → 操作按钮 → 快捷指令 → 麦一下 | iPhone 15 Pro 及之后 |
| 背面轻点 | 设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下 → 麦一下 | iPhone 8 及之后 |
| NFC 贴纸 | 快捷指令 → 自动化 → 新建 → NFC → 扫描贴纸 → 运行「麦一下」，输入填 `work` / `home` / `car`；选「立即运行」 | iPhone XS 及之后 |

三张贴纸分别对应三个场景：工位贴纸走到店自取，家门口贴纸走麦乐送，车里贴纸走得来速。

## 3. 关闹钟就订早餐

自动化 → 新建 → 闹钟 → 「被停止时」，动作：

| # | 动作 | 设置 |
| --- | --- | --- |
| 1 | 获取 URL 内容 | `{服务}/v1/plan`，POST，请求体 `{"scene":"breakfast","inMinutes":25}` |
| 2 | 从菜单中选取 | 提示语用第 1 步的 `say`；选项「下单」「今天不吃」 |
| 3 | 「下单」分支：获取 URL 内容 | `{服务}/v1/confirm/` + 第 1 步的 `planId`，POST |
| 4 | 打开 URL | 第 3 步的 `payPage` |

`inMinutes` 是起床到门店的通勤时间，服务会换算成预约取餐时间（`reservationDate`）。

## 4. 日历空档点餐

自动化 → 新建 → 特定时间 → 每天 11:00，动作：

| # | 动作 | 设置 |
| --- | --- | --- |
| 1 | 查找日历日程 | 开始日期是今天，结束日期在 11:30 到 14:00 之间；按结束日期最晚排序；限制 1 个 |
| 2 | 调整日期 | 第 1 步的结束日期加 10 分钟 |
| 3 | 格式化日期 | 自定义格式 `HH:mm` |
| 4 | 获取 URL 内容 | `{服务}/v1/plan`，POST，请求体 `{"scene":"work","at":"第 3 步"}` |
| 5 | 同「关闹钟」第 2 到 4 步 | 菜单确认、下单、打开付款页 |

## Android

用 Tasker 或 HTTP Shortcuts：建一个 POST `{服务}/v1/press` 的请求，放到桌面小组件或快捷设置磁贴即可，返回字段与上文相同。
